About the lab

How the lab runs

OpenClaw runs on Ubuntu in AWS EC2. Nexus uses external model APIs, starting with OpenAI. The Dashboard is accessed through a private SSH tunnel. The lab is isolated from production systems, and Docker tool containment remains a validation task.

How experiments are evaluated

Each experiment starts with a question, uses a small implementation, and records observations and limits. Model comparisons consider response quality, tool reliability, latency, context usage, and cost.
